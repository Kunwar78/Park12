# PCN lookup demo (fictional study project)

Requires Node 18+. No npm install needed.

    node server.js

- Public search:  http://localhost:3000
- Admin:          http://localhost:3000/admin.html  (default login admin / admin123)

Change the login: `ADMIN_USER=me ADMIN_PASS=secret node server.js`
Records are stored in data.json (created on first run with one sample record: AB12 CDE / DM00000001).

Keep the "fictional demo" banner and neutral name. Do not use a real council's name or logo.
